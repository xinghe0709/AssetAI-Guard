    AssetGuard AI

    A web-based decision-support portal for structural load requests — from engineering drawings to compliant / non-compliant outcomes.

    Client: GJP Engineering

    Start presentation →

    01 · Problem statement

    Limits of the current workflow

    Maintenance staff and contractors often need to place equipment on bridges, platforms, or building areas. Today, assessment relies on manual review of engineering drawings.

    • Heavy dependence on manual drawing interpretation
    • Hard to confirm the latest drawing version and key limit data
    • Requires strong engineering knowledge — difficult for non-engineers
    • Outcomes can vary between staff members
    • Slow end-to-end process with limited audit traceability

    02 · Rationale

    What we are building

    A decision-support portal for GJP Engineering: compare proposed loads to design limits, log every check, and return Compliant or Non-Compliant — faster and more consistent than manual drawing review, without replacing engineering judgement.

    Compliant

    Compliant — next steps

    1. System shows a clear Compliant result on the evaluation screen
    2. Evaluation is saved to the database (user, asset, load, timestamp)
    3. Contractor may proceed with the planned work, subject to site conditions
    4. Asset Manager can review the record on the dashboard at any time
    5. Optional: user triggers an email report to the contractor and Asset Manager
    Non-Compliant

    Non-Compliant — next steps

    1. System shows Non-Compliant — proposed load exceeds the structural limit
    2. Evaluation is still saved for traceability and audit purposes
    3. Contractor should not proceed until engineering review
    4. Asset Manager reviews the alert and history on the dashboard
    5. Comments and load details are kept for follow-up assessment or revised submission

    03 · MVP agreement

    Agreed scope with GJP Engineering

    Login

    Login & access

    The System Admin creates accounts for Asset Managers and Contractors. MVP has no self-signup or forgot-password — agreed with GJP in March 2026.

    Implemented in AssetGuard-AI (JWT auth, roles) and assetguard-ui (login and first-time password setup).

    Assets

    Asset selection & load input

    Users pick an asset (bridge, platform, building area, etc.) and enter load value, units, equipment context, and a comments field — e.g. crane outriggers or spreader plates.

    Data can be entered manually or imported from AI-extracted JSON via the extraction tool and backend import API.

    Comparison

    Limit comparison

    The evaluation engine compares the proposed load to stored design limits using rule-based numeric checks and unit conversion.

    This is not FEA or advanced structural modelling — it supports faster, consistent screening before engineering review when needed.

    Results

    Result display

    Each request returns a clear Compliant or Non-Compliant outcome on the evaluation screen.

    Built in the UI evaluation flow and AssetGuard-AI evaluation APIs so contractors and managers see the same unambiguous result.

    Dashboard

    Records & dashboard

    Every evaluation is stored — user, asset, load, result, and timestamp — for traceability and audit, whether or not email is sent.

    The dashboard shows history and alerts; GJP asked us to prioritise it over the external email feature if time is limited.

    Email

    Optional email

    Reports are sent only when the user triggers them — not automatically — to avoid spam and keep control with the operator.

    Recipients include the contractor and Asset Manager; the record always remains in the database for formal traceability.

    04 · User roles

    Who uses the system

    System Admin

    Account & access control

    • Create, update, and deactivate user accounts
    • Assign roles (Admin, Asset Manager, Contractor)
    • Full access to admin areas (users, locations, system setup)
    • No self-signup — all accounts are admin-provisioned for MVP

    Asset Manager

    Assets & oversight

    • Add, edit, and remove assets and related structural data
    • Import or maintain load limits used in evaluations
    • Review evaluation history, alerts, and dashboard records
    • Oversee contractor submissions and compliance outcomes

    Contractor

    Field load requests

    • Select an asset and submit a proposed load (value, units, comments)
    • Run evaluations and view Compliant / Non-Compliant results
    • Optionally trigger email reports to themselves and the Asset Manager
    • Cannot add, edit, or delete assets (Asset Manager only)

    05 · Core workflow

    End-to-end load assessment

    1. User signs in with an assigned role
    2. Select the target asset (bridge, platform, building area, etc.)
    3. Enter proposed load, units, equipment context, and comments
    4. System compares input against design limits from drawings / data
    5. Receive Compliant or Non-Compliant result
    6. Evaluation stored in database; email sent only if user chooses

    06 · Architecture

    Project structure overview

    Three repositories in one workspace — extraction tool and backend run as separate apps.
