AssetGuard AI

Decision-support for engineering load compliance — from drawings to on-site checks.

Client: GJP Engineering · UWA CITS5206 Capstone

User workflow Demo video
Client problem

The challenge

GJP needs a faster, traceable way to compare equipment loads against design limits at port assets.

Scattered limits

Capacities live in PDFs — hard to access on site.

Slow checks

Manual comparison is error-prone.

Weak audit trail

Outcomes and alerts are not centralised.

Our solution

Summary

Web platform plus AI pipeline: ingest criteria, manage assets, evaluate loads, log results, notify when non-compliant.

  • AI tool — OCR + LLM from PDF/images to JSON
  • Backend — auth, assets, evaluations, email alerts
  • Web UI — role-based workflows

MVP: decision-support only — not a replacement for engineering judgement.
